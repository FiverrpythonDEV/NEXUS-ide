# NEXUS // Персональний Технологічний Дашборд

**NEXUS** — це повнофункціональний, преміальний веб-застосунок та персональний робочий простір, розроблений спеціально для девелоперів, системних інженерів та тех-ентузіастів. Він поєднує в собі щоденні інструменти кодування, планувальник проєктів, каталог гаджетів та базу знань Obsidian-стилю.

---

## 🛠️ Архітектурна Структура Проєкту

Застосунок розроблений за суворим модульним підходом. Кожен розділ є ізольованою одиницею, що полегшує його розширення та налагодження.

```bash
/src
  ├── components/
  │   ├── ui/               # Спільні UI-компоненти дизайн-системи (Кнопки, Картки, Модалки тощо)
  │   ├── Sidebar.tsx       # Ліва вертикальна навігація (підтримує згортання)
  │   ├── Header.tsx        # Верхня панель інструментів (пошук, час, статус)
  │   └── CommandPalette.tsx # Командний рядок Ctrl+K / Cmd+K для швидкої навігації та дій
  ├── context/
  │   └── AppContext.tsx    # Глобальний стейт-менеджер (зберігання та синхронізація станів)
  ├── modules/
  │   ├── registry.ts       # Єдиний Реєстр Модулів (сюди додаються нові розділи)
  │   ├── dashboard/        # Головний екран, віджети діагностики та статистики
  │   ├── code-tools/       # 6 корисних утиліт розробника (JSON, Regex, Кольори, Base64, Epoch)
  │   ├── project-tracker/  # Канбан-планувальник проєктів
  │   ├── gadget-inventory/ # Каталог та облік парку техніки
  │   └── settings/         # Меню налаштувань (акценти, розмітка, бекапи)
  ├── types/
  │   └── index.ts          # Спільні типізовані контракти та TypeScript-інтерфейси
  ├── utils/
  │   └── storage.ts        # Єдиний шар роботи з localStorage та бекапами
  ├── App.tsx               # Кореневий диспетчер, жива синхронізація CSS-змінних
  ├── index.css             # Головна дизайн-система Tailwind v4
  └── main.tsx              # Точка входу в застосунок
```

## 🚀 Як додати новий Модуль у систему?

Завдяки автоматизованому реєстру, розширення застосунку новим розділом займає менше хвилини і не потребує зміни розмітки `Sidebar` чи `App.tsx`:

1. **Створіть свій модуль** у папці `/src/modules/` (наприклад, `/src/modules/my-tool/MyToolModule.tsx`).
2. **Додайте унікальний ідентифікатор** у файл `/src/types/index.ts` у тип `ModuleId`:
   ```typescript
   export type ModuleId = 'dashboard' | ... | 'my-tool';
   ```
3. **Зареєструйте модуль** у реєстрі `/src/modules/registry.ts`, додавши новий об'єкт у масив `MODULE_REGISTRY`:
   ```typescript
   import { MyToolModule } from './my-tool/MyToolModule';
   import { Activity } from 'lucide-react'; // або будь-яка інша іконка
   
   export const MODULE_REGISTRY: ModuleEntry[] = [
     // ... інші модулі
     {
       id: 'my-tool',
       name: 'Мій Інструмент',
       icon: Activity,
       description: 'Опис того, що робить цей інструмент розробника.',
       component: MyToolModule,
     }
   ];
   ```
4. **Готово!** Новий модуль автоматично з'явиться в меню навігації (`Sidebar`), заголовку (`Header`) та стане доступним для миттєвого переходу через Командну палітру (`Ctrl+K`).

## 💾 Шар Зберігання та Синхронізація (Storage Layer)

Усі дані користувача надійно зберігаються у вашому браузері за допомогою `localStorage`:
- Усі операції читання/запису здійснюються через об'єкт `storage` у файлі `/src/utils/storage.ts`.
- Дані є строго типізованими (`Project[]`, `Note[]`, `Gadget[]`, `AppSettings`).
- У разі відсутності збережених даних, застосунок автоматично завантажує реалістичні демонстраційні дані розробника, щоб робочий простір одразу виглядав наповненим та готовим до тестів.
- В модулі **Налаштування** реалізовано повнофункціональний експорт та імпорт всієї бази у форматі `.json` для створення резервних копій.

## 🎨 Дизайн-система & Зворотний Зв'язок (UX)

- **Колірне свічення (Neon Glow)**: Елементи налаштовують кольорові тони автоматично. При зміні теми у налаштуваннях (`settings.accentColor`), кореневий компонент `App.tsx` оновлює CSS-змінні `--color-accent-purple` та `--color-accent-purple-glow` на рівні документа, миттєво підлаштовуючи весь UI.
- **Micro-interactions**: Всі кнопки та картки мають плавні hover-анімації (`ease-out`, `glow-hover`).
- **Командна Палітра**: Натисніть `Ctrl+K` або `Cmd+K` у будь-якому місці для навігації без миші.
